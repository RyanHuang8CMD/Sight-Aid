SightAid AI is a real-time web-based visual assistance application for visually impaired people.
Combining device camera and multimodal large language model, it provides scene description, object detection, obstacle warning, text reading and navigation assistance. It helps visually impaired users perceive the world through audio feedback.

This project adopts cloud AI architecture. It is lightweight, runs directly in browser without app installation, and works on mobile phones, tablets and computers.

## ✨ Key Features
- Real-time scene understanding: Analyze camera frames and describe environments, people, objects and road conditions.
- Obstacle & hazard alert: Detect barriers, steps, vehicles and nearby objects with instant voice warning.
- Text reading via OCR: Recognize text on books, bills, road signs and menus and read aloud.
- Navigation aid: Distinguish walkable areas and danger zones to support safe walking.
- Pure web deployment: No download required. Cross-device compatible.
- Accessibility-first design: Minimal UI, full voice interaction, simple operation for visually impaired users.

## 📌 Functions
### 1. Panoramic Scene Recognition
Analyze camera feed in real time, tell users whether they are indoors or outdoors, in streets, rooms or public spaces, and describe crowd density.

### 2. Obstacle & Danger Warning
Detect obstacles, low-hanging items, steps, vehicles and pedestrians. Voice alerts to prevent collision and falls.

### 3. OCR Text-to-Speech
Extract text from paper, books, labels and screens and convert it to speech.

### 4. Daily Object Recognition
Identify daily goods, food, cups, clothes and home appliances for independent living.

### 5. Lightweight Web App
Built for web browsers. Works on mobile browsers with low resource consumption and fast response.

## 🛠 Tech Stack
- Frontend: HTML / CSS / JavaScript, mobile responsive layout
- Backend: Node.js / TypeScript cloud service
- AI Capabilities: Multimodal visual model, real-time image analysis, OCR, text-to-speech
- Deployment: One-click cloud sandbox deployment, public web access

## 🚀 How to Use
1. Open the deployed web link
2. Grant camera, microphone and audio playback permission
3. Point camera toward scenes, objects or text
4. The system automatically analyzes and speaks the result

Supported devices: Android / iOS phones, tablets, PC browsers

## 🎯 Project Motivation
Most existing assistive devices for the blind are expensive, complicated and hard to carry.
SightAid AI aims to provide low-cost AI visual assistance for visually impaired users, improving their independence in daily life, travel and study.

This is an open-source non-profit project. We keep iterating to build better accessibility technology.
